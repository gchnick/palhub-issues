# 🐛 Reporte de Issues y Sugerencias - PalHub

¡Bienvenido/a al espacio oficial de seguimiento de errores y propuestas para **PalHub**!

**PalHub** es un ecosistema de aplicaciones para la gestión de la congregación: registro de territorios, programa de predicación, registros del secretario, contabilidad, programa de la reunión Vida y Ministerio y una app móvil para los publicadores.

Como nuestro repositorio de código fuente es privado, utilizamos este espacio público exclusivamente para gestionar los *issues*, reportar bugs y recibir sugerencias de la comunidad.

---

## 🚨 ¿Encontraste un error (Bug)?

Antes de crear un nuevo reporte, por favor verifica si ya existe uno similar abierto en la pestaña de [Issues](../../issues). Si ya está reportado, puedes dejar una reacción o un comentario aportando más información en lugar de abrir uno duplicado.

Si vas a crear un nuevo *issue*, por favor incluye la siguiente información para ayudarnos a solucionarlo más rápido:

1. **Descripción clara:** Explica qué estabas haciendo y qué sucedió exactamente.
2. **Pasos para reproducir:** Detalla el paso a paso de cómo llegar al error.
3. **Comportamiento esperado:** Qué deberías haber visto en lugar del error.
4. **Entorno (si aplica):**
   - Dispositivo o navegador web.
   - Sistema operativo.
   - Rol con el que iniciaste sesión (p. ej. siervo de territorio, secretario, publicador).
   - Versión de la aplicación.
5. **Capturas de pantalla o logs:** Si tienes imágenes, GIFs o mensajes de error de la consola, adjúntalos.

👉 **[Crear un nuevo reporte de bug](../../issues/new?template=bug_report.md)**

## 💡 ¿Tienes una sugerencia o nueva idea?

¡Las propuestas de mejora son bienvenidas!

* Abre un nuevo *issue* seleccionando la plantilla de solicitud de característica.
* Describe de qué se trata la funcionalidad y por qué crees que sería útil para el proyecto.
* Si tienes referencias de otras aplicaciones o bocetos, ¡adjúntalos!

👉 **[Sugerir una nueva característica](../../issues/new?template=feature_request.md)**

## 🏷️ Etiquetas

Usamos etiquetas para organizar y priorizar los reportes. Estas son las más comunes:

| Etiqueta | Descripción |
| --- | --- |
| `bug` | Error o comportamiento inesperado |
| `enhancement` | Mejora sobre una funcionalidad existente |
| `feature` | Nueva funcionalidad que no existe |
| `needs info` | Se necesita más información para continuar |
| `in progress` | Alguien está trabajando en ello |
| `ready` | Listo para ser trabajado |
| `blocked` | Bloqueado por una dependencia externa |
| `priority: high` / `medium` / `low` | Nivel de prioridad |
| `app-desktop` | Relacionado con la app de escritorio (SPA) |
| `app-mobile` | Relacionado con la app móvil (PWA) |
| `api` | Relacionado con la API |
| `landing` | Relacionado con el sitio público |
| `documentation` | Mejoras en la documentación |
| `duplicate` | Duplicado de otro issue |
| `wontfix` | No se planea resolver |

> Puedes ver todas las etiquetas disponibles en la pestaña [Labels](../../labels).

---

## ⚠️ Notas importantes

* **Por favor, no incluyas información sensible:** No compartas contraseñas, tokens de API, datos personales de publicadores ni información financiera en los reportes públicos.
* **Vulnerabilidades de seguridad:** Si necesitas reportar una vulnerabilidad de seguridad, **no abras un issue público**. Escríbenos de forma privada a `seguridad@palhub.example` *(reemplaza por el correo oficial de seguridad)*.
* Este repositorio es únicamente para incidencias y feedback. Las preguntas de soporte general o consultas comerciales deben dirigirse al sitio oficial del proyecto.

¡Gracias por ayudarnos a mejorar PalHub! 🚀
